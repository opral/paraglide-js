# Vite locale split fixture

This tiny client-rendered Vite app uses `experimentalClientLocaleSplit`. It keeps the saved locale in `localStorage`, falls back to English, can switch the active page language in place, and previews a German greeting without changing the active locale.

The compiler API use follows the public docs in `docs/compiling-messages.md`: `loadLocale("de")` loads the German message chunk, and `m.greeting(..., { locale: "de" })` formats one message for the preview. The preview does not call `setLocale`. The selector awaits `setLocale(locale, { reload: false })` and rerenders the client-owned page.

## Replay

Use Node.js 22.12 or newer and a built local checkout of `@inlang/paraglide-js` that supports `experimentalClientLocaleSplit`. Point `PARAGLIDE_COMPILER_PATH` at that checkout; the setup script keeps the published compiler out of the runtime install while leaving the lockfile portable.

From this directory:

```sh
PARAGLIDE_COMPILER_PATH=/path/to/paraglide-js npm run setup
npx playwright install chromium
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

In another shell, run the browser check:

```sh
npm run verify
```

Set `PREVIEW_URL` if the production preview is hosted somewhere else. The verification script expects a production build and preview server; it does not run performance timings.

The generated `src/paraglide/` and `dist/` outputs are ignored and are regenerated by the compiler and Vite during replay.
